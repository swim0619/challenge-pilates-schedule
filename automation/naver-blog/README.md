# 네이버 블로그 자동 글쓰기

주제 하나만 주면 **네이버에서 글감을 모으고 → Claude 가 글을 쓰고 → 어울리는 사진을
찾아 붙이고 → 네이버 블로그에 임시저장**까지 해줍니다.

발행(공개)은 하지 않습니다. 항상 **임시저장**까지만 하고, 마지막 확인과 발행 버튼은
사람이 누릅니다.

---

## 1. 처음 한 번만 준비하기

```bash
cd automation/naver-blog
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp .env.example .env
```

`.env` 를 열어 **`ANTHROPIC_API_KEY`** 하나만 채우면 바로 쓸 수 있습니다.
(https://console.anthropic.com/settings/keys 에서 발급)

나머지는 전부 선택 사항입니다:

| 항목 | 없으면 어떻게 되나 |
|---|---|
| `NAVER_CLIENT_ID` / `SECRET` | 오픈 API 대신 **크롬으로 네이버 검색결과를 직접 읽어** 글감을 모읍니다 |
| `PEXELS_API_KEY` | 위키미디어 공용(CC 라이선스) 사진을 씁니다 |
| `NAVER_BLOG_ID` | 로그인 세션에서 자동으로 알아냅니다 |
| `SUPABASE_URL` / `ANON_KEY` | `--save-supabase` 를 못 씁니다 (관리자 화면 연동만 빠짐) |

## 2. 네이버 로그인 (처음 한 번)

```bash
./run.sh login
```

크롬이 **원격 디버깅 모드**로 뜨고 네이버 로그인 화면이 열립니다.
**아이디·비밀번호는 사용자가 그 창에서 직접 입력합니다.** 이 도구는 로그인 정보를
읽지도, 입력하지도, 저장하지도 않습니다.

로그인이 끝나면 자동으로 다음 단계로 넘어갑니다. 세션은 `chrome-profile/` 폴더에
남아 다음부터는 이 단계를 건너뜁니다. 평소 쓰는 크롬 프로필과 완전히 분리돼 있어서
기존 브라우저에는 아무 영향이 없습니다.

> 크롬을 직접 띄우고 싶으면 `./chrome.sh` 를 쓰세요 (같은 포트, 같은 프로필).

## 3. 글 쓰기

```bash
# 글감 수집 → 글 작성 → 사진 → 네이버 임시저장까지 한 번에
./run.sh write "필라테스 일주일에 몇 번이 좋을까"

# 네이버는 건드리지 않고 글만 만들어 확인 (추천: 처음엔 이걸로)
./run.sh write "거북목 스트레칭" --dry-run

# 만들어 둔 초안만 나중에 올리기
./run.sh post out/20260827-2210-거북목-스트레칭/post.json
```

### 자주 쓰는 옵션

| 옵션 | 설명 |
|---|---|
| `--count 8` | 모을 글감 수 (기본 8) |
| `--images 4` | 넣을 사진 수 (기본 4) |
| `--images-from local` | `images/` 폴더의 **우리 스튜디오 사진만** 사용 |
| `--length 2000` | 목표 분량(자) |
| `--note "수업 안내는 빼줘"` | 추가 요청사항을 그대로 전달 |
| `--no-images` | 사진 없이 글만 |
| `--save-supabase` | `blog_drafts` 테이블에도 저장 → 관리자 > 블로그 메뉴에서 검토 |
| `--keep-open` | 끝난 뒤 크롬 창을 그대로 둡니다 (바로 발행하고 싶을 때) |

### 결과물

```
out/20260827-2210-거북목-스트레칭/
├── post.json      ← 다시 올릴 때 쓰는 원본
├── post.md        ← 눈으로 확인하는 미리보기
├── images/        ← 내려받은 사진
└── screenshot.png ← 임시저장 직후 에디터 화면
```

## 동작 방식

```
주제
 └─ 1. 글감 수집   nblog/collect.py
      네이버 블로그·뉴스 검색 → 상위 글 본문까지 읽어옴
      (오픈 API 키가 있으면 API, 없으면 크롬으로 검색결과 스크랩)
 └─ 2. 글쓰기      nblog/compose.py
      Claude 에게 자료를 넘기고 블록 구조(JSON)로 글을 받음
      원문 복붙 금지 · 과장된 효능/의학적 단정 금지를 시스템 프롬프트에 명시
 └─ 3. 사진        nblog/imagery.py
      images/ 내 사진 → Pexels → 위키미디어 공용 순으로 검색·다운로드
      직접 찍은 사진이 아니면 캡션에 출처를 남김
 └─ 4. 임시저장    nblog/browser.py + nblog/editor.py
      CDP 로 크롬에 붙어 스마트에디터 ONE 을 조작
```

### 글에 들어가는 서식

| 블록 | 에디터에서 |
|---|---|
| `heading` | 이모지 + **굵게** + 글자 크기 19 (소제목) |
| `paragraph` | 1~2문장마다 줄바꿈 — 블로그 특유의 짧은 호흡. `**강조**` 는 굵게 |
| `list` | `· 항목` |
| `quote` | 에디터 인용구 블록 |
| `callout` | 💡 + 굵게 |
| `divider` | 에디터 구분선 |
| `image` | 사진 첨부 + 캡션(+출처) |

**태그**는 네이버에서 *발행 설정 화면*에서만 입력할 수 있어서, 임시저장 단계에서는
본문 맨 끝에 `#태그` 형태로 적어둡니다. 발행할 때 태그란에 옮겨 붙이시면 됩니다
(`post.md` 맨 아래에도 같은 목록이 있습니다).

## 안전장치

- **발행 버튼은 누르지 않습니다.** `저장`(임시저장)만 클릭하고, 텍스트에 "발행"이
  들어간 버튼은 코드에서 아예 클릭 대상에서 제외합니다
  (`selectors.py` 의 `FORBIDDEN_BUTTON_TEXT`).
- **로그인 정보를 다루지 않습니다.** 로그인은 사람이 크롬 창에서 직접 합니다.
- 사진은 무료/CC 라이선스 소스만 씁니다. 직접 찍은 사진이 아니면 캡션에 저작자와
  라이선스를 남깁니다. 상업적 사용 조건은 발행 전에 한 번 확인해 주세요.
- 수집한 글은 **참고용**으로만 모델에 넘기고, 문장은 새로 쓰게 합니다. 그래도 발행
  전에 `post.md` 를 읽어보고 사실관계를 확인하는 편이 좋습니다.

## 네이버가 화면을 바꿔서 안 될 때

스마트에디터 DOM 이 바뀌면 `nblog/selectors.py` 만 고치면 됩니다. 각 항목은
"먼저 맞는 것을 쓴다"는 후보 목록이라, 새 셀렉터를 **맨 앞에 한 줄 추가**하면 됩니다.
버튼을 못 찾으면 그 서식만 건너뛰고 글쓰기는 계속되므로, 글 전체가 날아가지는 않습니다.
